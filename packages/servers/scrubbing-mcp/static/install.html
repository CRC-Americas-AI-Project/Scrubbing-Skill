Etapa 1 — Instalar o Servidor (Mac)

O script configura tudo automaticamente: Homebrew, Node.js, Git e o servidor MCP.

✅
Pré-requisitos instalados automaticamente
  • Homebrew — gerenciador de pacotes do Mac (instalado se ausente)
  • Node.js 20+ — instalado via Homebrew se ausente
  • Git — instalado via Xcode Tools se ausente
1
Abra o Terminal
Pressione ⌘ Command + Espaço, digite Terminal e pressione Enter
💡
Primeira vez usando o Terminal?

Pressione ⌘ Command + Espaço ao mesmo tempo, escreva Terminal e pressione Enter. Uma janela de texto vai abrir — é aí que você vai colar o comando abaixo.

2
Cole o comando de instalação
Copie e cole no Terminal com ⌘V, depois pressione Enter
curl -fsSL https://raw.githubusercontent.com/CRC-Americas-AI-Project/Scrubbing-Skill/main/install.sh | bash
⏳
Aguarde 2 a 3 minutos

Não feche o Terminal enquanto o processo estiver rodando.

✅
Quando aparecer "Instalação concluída!" — está pronto

Você pode fechar o Terminal após essa mensagem.

3
Inicie o servidor pela primeira vez
Clique duas vezes no arquivo "SAP Scrubbing MCP.command" na sua Área de Trabalho
▶️
Execute o atalho na Área de Trabalho

Localize o arquivo "SAP Scrubbing MCP.command" na sua Área de Trabalho e clique duas vezes para iniciar o servidor. Uma janela do terminal vai abrir — aguarde até aparecer a mensagem confirmando que o servidor está rodando.

✓
Servidor instalado
O servidor inicia automaticamente no próximo login do Mac

Um arquivo "SAP Scrubbing MCP.command" foi criado na sua Área de Trabalho para iniciar o servidor manualmente quando necessário.

🔄
Início automático ativo

Nas próximas sessões do Mac, o servidor já inicia automaticamente — sem nenhuma ação sua.

Etapa 1 — Instalar o Servidor (Windows)

O script configura tudo automaticamente: Node.js, Git e o servidor MCP.

✅
Pré-requisitos instalados automaticamente
  • Node.js 20+ — instalado via winget se ausente
  • Git — instalado via winget se ausente
1
Abra o PowerShell
Pressione ⊞ Win + X e selecione "Terminal" ou "Windows PowerShell"
💡
Primeira vez usando o PowerShell?

Pressione ⊞ Windows + X ao mesmo tempo e clique em "Terminal" ou "Windows PowerShell" no menu que aparecer.

2
Cole o comando de instalação
Copie e cole no PowerShell com Ctrl+V, depois pressione Enter
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass; iwr https://raw.githubusercontent.com/CRC-Americas-AI-Project/Scrubbing-Skill/main/install.ps1 -OutFile "$env:TEMP\install.ps1"; & "$env:TEMP\install.ps1"
⏳
Aguarde 2 a 3 minutos

Não feche o PowerShell enquanto o processo estiver rodando.

🛡️
Aviso de segurança do Windows?

Se aparecer "O Windows protegeu seu computador", clique em "Mais informações" e depois em "Executar assim mesmo". Isso é normal para scripts PowerShell.

✅
Quando aparecer "Instalação concluída!" — está pronto

Você pode fechar o PowerShell após essa mensagem.

3
Inicie o servidor pela primeira vez
Clique duas vezes no arquivo "SAP Scrubbing MCP.bat" na sua Área de Trabalho
▶️
Execute o atalho na Área de Trabalho

Localize o arquivo "SAP Scrubbing MCP.bat" na sua Área de Trabalho e clique duas vezes para iniciar o servidor. Uma janela do terminal vai abrir — aguarde até aparecer a mensagem confirmando que o servidor está rodando.

✓
Servidor instalado
Atalho "SAP Scrubbing MCP.bat" criado na Área de Trabalho

Prefere baixar o arquivo manualmente? Clique aqui para baixar install.ps1 e execute com clique direito → "Executar com o PowerShell".

🔄
Início automático ativo

Etapa 3 — Instalar a Scrubbing Skill

A Skill é um conjunto de instruções que ensina o Joule Desktop a executar o processo oficial de scrubbing SAP — naming convention, cálculo de IPCA, atualização do Renewal Execution e muito mais.

ℹ️
O que a Skill faz

Ela orienta o Joule a seguir o fluxo oficial SAP CRC: leitura do Harmony, consulta ao DCD, análise do PDF do contrato, cálculo de IPCA, atualização do título (naming convention), preenchimento do Renewal Execution e geração de relatório — tudo via MCP, sem abrir o navegador.

1
Baixe o arquivo da Skill
Clique no botão abaixo para baixar o arquivo skill.md
2
Abra o painel de Extensions no Joule Desktop
Clique no ícone de banco de dados (⊞) na barra lateral esquerda

Na barra de navegação lateral do Joule Desktop, clique no ícone de Extensions (parece um banco de dados / cilindro). Em seguida, clique na aba Skills.

3
Importe a Skill
Extensions → Skills → + New → Import
  1. Clique em "+ New" no topo do painel de Extensions
  2. Selecione "Create Skill"
  3. Escolha a opção "Import"
  4. Selecione o arquivo skill.md que você baixou no Passo 1
  5. Confirme a instalação
✓
Skill instalada
Ela aparece na lista de Skills com o nome "scrubbing skill"
✅
Verificação rápida

Na lista de Skills (Extensions → Skills), você deve ver a skill "scrubbing skill" com a descrição: "Scrubbing de oportunidades SAP no Harmony..."

⚠️
Mantenha menos de 20 skills instaladas

O Joule Desktop tem melhor desempenho com até 20 skills ativas. Se tiver mais, desative as que não usa.

Etapa 2 — Adicionar o Conector no Joule

Registre o servidor MCP local no Joule Desktop para que ele consiga se comunicar com o Harmony SAP.

⚠️
Complete a etapa 1 antes de continuar

O servidor MCP precisa estar instalado (Mac / Windows) antes de adicionar o conector.

1
Abra o painel de Extensions
Clique no ícone de banco de dados na barra lateral esquerda → aba Connectors

Na barra de navegação lateral do Joule Desktop, clique no ícone de Extensions e depois na aba Connectors.

2
Adicione um novo conector
Extensions → Connectors → + New → Add Connector

Clique em "+ New" no topo do painel, depois selecione "Add Connector".

3
Preencha os campos do conector
Copie exatamente os valores abaixo
CampoValor
NameSAP Scrubbing MCP
URLhttp://localhost:8812/mcp
AuthNone
💡
O que é "localhost"?

localhost significa "este computador". Essa URL só funciona na sua máquina — não compartilhe com outras pessoas.

4
Ative o conector na conversa
O conector precisa estar ativo em cada conversa onde você quiser usar o scrubbing

Após salvar, abra uma conversa no Joule Desktop. Na barra de input, clique no ícone de Connectors e certifique-se de que SAP Scrubbing MCP está habilitado para essa conversa.

5
Teste o conector
Confirme que o servidor e a skill estão funcionando corretamente

Abra uma nova conversa e pergunte ao Joule:

"Quem sou eu no Harmony SAP?"
✅
Se aparecer seu nome e I-number — está tudo funcionando!

O servidor MCP está conectado ao Harmony e o Joule está pronto para fazer scrubbing.

⏱
Primeira vez pode demorar ~10 segundos

O servidor faz login automático no SAP na primeira chamada da sessão.

Servidor instalado e conector configurado

❓ Perguntas Frequentes

O servidor não iniciou automaticamente. O que faço?▼
Mac: Clique duas vezes no arquivo "SAP Scrubbing MCP.command" na sua Área de Trabalho.

Windows: Clique duas vezes no arquivo "SAP Scrubbing MCP.bat" na sua Área de Trabalho.
O Joule diz "não foi possível conectar". O que faço?▼
1. Verifique se o servidor está rodando: abra o navegador e acesse http://localhost:8812/mcp
2. Se não responder, inicie o servidor clicando no atalho na Área de Trabalho.
3. Verifique se o conector está ativo na conversa (ícone de Connectors na barra de input).
4. Tente novamente no Joule.
Apareceu um erro de segurança no Windows. O que faço?▼
Clique em "Mais informações" na janela de aviso e depois em "Executar assim mesmo". Isso é esperado para scripts PowerShell que não são da Microsoft Store.
Não encontro a aba Skills no Joule. Onde fica?▼
Na barra de navegação lateral esquerda do Joule Desktop, clique no ícone de Extensions (parece um cilindro/banco de dados). Na parte superior do painel que abre, você verá duas abas: Skills e Connectors. Clique em Skills.
Precisa reinstalar quando atualizar o computador?▼
Não. A instalação do servidor MCP é permanente e inicia automaticamente no login. A skill fica salva no Joule Desktop. Para atualizar para uma versão mais nova, basta executar o script de instalação novamente.
Como parar o servidor MCP?▼
Mac: Abra o Terminal e execute:
launchctl unload ~/Library/LaunchAgents/com.sap.scrubbing.plist

Windows: Abra o Agendador de Tarefas, localize "SAP Scrubbing MCP" e clique em "Desabilitar".
Como atualizar a Skill para uma versão mais nova?▼
1. Baixe o novo arquivo skill.md do repositório.
2. No Joule Desktop, vá em Extensions → Skills, selecione a skill "scrubbing skill" e clique em "Uninstall" (menu de três pontos).
3. Reinstale seguindo os passos da Etapa 2.
Os cookies SAP expiraram. Como renovar?▼
O servidor renova a autenticação automaticamente. Se o Joule reportar que os cookies expiraram, ele mesmo vai executar o procedimento de renovação. Se persistir, reinicie o servidor clicando no atalho na Área de Trabalho.
