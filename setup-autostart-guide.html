Setup: Servidor MCP SAP para Joule Desktop

Configure o conector SAP (Harmony + DCD) para iniciar automaticamente toda vez que você abrir a Joule — sem precisar fazer nada na mão.

SAP CRC Americas · Time de Renovações

O que isso faz

O servidor MCP é um programa local que funciona como ponte entre a Joule e os sistemas SAP (Harmony e DCD). Sem ele, a Joule conversa normalmente mas não consegue ler oportunidades nem baixar contratos. Este setup faz o servidor subir automaticamente no login do Windows e toda vez que você abrir a Joule pelo novo atalho.

Instalação — 3 passos

1

Baixar o repositório do time

Abra o PowerShell (tecla Windows → digite "PowerShell" → Enter) e rode:

cd $env:USERPROFILE git clone https://github.com/CRC-Americas-AI-Project/Scrubbing-Skill.git .sap-scrubbing cd .sap-scrubbing npm install
Já tem o repositório? Entre na pasta %USERPROFILE%\.sap-scrubbing e rode git pull para atualizar, depois continue para o Passo 2.
2

Rodar o setup de auto-start

Dentro da pasta .sap-scrubbing, dê duplo clique no arquivo setup-autostart.bat — ou rode pelo PowerShell:

.\setup-autostart.bat

O script vai:

  • Criar um arquivo de auto-start na pasta Startup do Windows (servidor sobe a cada login)

  • Criar o launcher open-joule.bat que verifica se o servidor está ativo antes de abrir a Joule

  • Criar o atalho "Joule Desktop" na área de trabalho

  • Iniciar o servidor para a sessão atual

Se o Windows pedir confirmação de segurança para executar o .bat, clique em "Executar assim mesmo". O arquivo é do repositório oficial do time.
3

Abrir a Joule pelo novo atalho

Na área de trabalho, use o atalho "Joule Desktop" (com ícone roxo) para abrir a Joule daqui em diante. Ele garante que o servidor esteja pronto antes de a Joule carregar.

Importante: use sempre este atalho, não o original da Joule. A Joule em si é idêntica — a única diferença é que o conector SAP é verificado antes de abrir.

Como verificar se funcionou

Na barra de tarefas, ao abrir a Joule pelo novo atalho, um terminal minimizado deve aparecer com a mensagem:

SAP Scrubbing MCP ouvindo em http://localhost:8812/mcp

Dentro da Joule, diga "scrubbing [número da OPP]". Se ela começar a ler dados do Harmony sem pedir cookies, está tudo funcionando.

Como funciona (resumo simples)

  • Servidor local (porta 8812): programa que fica rodando em segundo plano e conecta a Joule ao Harmony e DCD — expõe as ferramentas de scrubbing

  • Startup do Windows: arquivo start-sap-scrubbing-mcp.bat na pasta Startup sobe o servidor automaticamente a cada login

  • Atalho launcher: o open-joule.bat verifica a porta 8812 antes de abrir a Joule — se o servidor não estiver rodando, sobe antes de abrir

Problemas comuns

O setup-autostart.bat abriu e fechou rápido sem fazer nada
Clique com o botão direito → "Executar como administrador". Se persistir, abra o PowerShell na pasta .sap-scrubbing e rode .\setup-autostart.bat para ver a mensagem de erro.
Erro "Node.js não encontrado"
Instale o Node.js em nodejs.org (versão 20 LTS). Após instalar, feche e reabra o PowerShell antes de rodar o setup novamente.
A Joule não encontra os conectores SAP
Verifique se o terminal do servidor aparece na barra de tarefas. Se não aparecer, feche a Joule e reabra pelo atalho "Joule Desktop". Confirme também que a VPN SAP está conectada.
Atalho "Joule Desktop" não apareceu na área de trabalho
O Joule Desktop pode estar instalado em um caminho diferente do padrão. Abra o PowerShell, rode where.exe "Joule Desktop.exe" 2>nul ou procure o executável manualmente, depois edite o arquivo open-joule.bat com o caminho correto.
Erro de autenticação (sessão SAP expirada)
Abra o Microsoft Edge, acesse o Harmony e aguarde o login SSO automático. Depois acesse o DCD da mesma forma. Volte à Joule e tente novamente — os cookies são renovados automaticamente pelo SSO corporativo.
