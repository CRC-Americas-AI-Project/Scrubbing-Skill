SAP Scrubbing MCP — Instalação

Guia rápido para o Joule Desktop

Mac Instalação

1
Abra o Terminal (Cmd+Espaço → digite "Terminal") e cole o comando abaixo:
curl -fsSL https://raw.githubusercontent.com/CRC-Americas-AI-Project/Scrubbing-Skill/main/install.sh | bash
Aguarde ~2 minutos. O servidor inicia automaticamente.
✅ Após concluir, o servidor inicia toda vez que você liga o computador — sem nenhuma ação necessária.

Windows Instalação

1
Baixe o arquivo install.ps1 que foi enviado para você.
2
Clique com o botão direito no arquivo → "Executar com o PowerShell"
Aguarde ~2 minutos. O servidor inicia automaticamente.
✅ Um atalho "SAP Scrubbing MCP.bat" é criado na sua área de trabalho. O servidor também inicia automaticamente no login.

Configurar o Joule Desktop

Joule Desktop → Settings → Extensions → Add Connector

CampoValor
NameSAP Scrubbing MCP
URLhttp://localhost:8812/mcp
AuthNone
⚠️ O Joule e o servidor precisam estar no mesmo computador. A URL localhost só funciona localmente.

Primeira utilização

Na primeira chamada ao Harmony, o servidor faz login SAP automaticamente usando as credenciais da sua máquina. Nenhuma ação necessária.
